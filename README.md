# 영역 변화 클릭 매크로 — 편집·자동 녹화 통합 버전

Windows용 컨트롤 패널 프로그램입니다. 사각형 영역의 변화 위치를 왼쪽으로 한 번 클릭하고, **설정한 총 횟수까지 감지를 이어간 뒤 자동 정지**합니다. 감지 간격·총 클릭 횟수·클릭 후 쿨타임을 패널에서 설정할 수 있습니다. 기본값은 감지 간격 0.3초, 총 1회 클릭, 쿨타임 1초입니다.

키보드·마우스·지연 동작을 직접 편집하거나 자동 녹화하여, 변화 위치 클릭 후 실행할 수 있습니다. 첨부 참고 프로그램의 주요 편집/녹화 기능을 자체 구현한 것으로, 원본 실행 파일을 실행·변조·재배포하지 않습니다.

## 실행

Windows 10/11과 .NET Framework 4.8 환경에서 사용합니다. Python이나 추가 패키지는 필요하지 않습니다.

1. 저장소를 다운로드하고 압축을 풉니다.
2. 프로젝트 폴더에서 Windows PowerShell로 `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1`을 실행합니다. 이 옵션은 해당 실행에만 적용됩니다.
3. 생성된 `dist\RegionChangeClicker.exe`를 실행합니다.

GitHub Actions의 **Windows build / Artifacts / RegionChangeClicker-Windows**에서도 빌드된 실행 파일을 받을 수 있습니다.

## 사용 방법

1. **영역 선택**을 누르고 화면에서 사각형을 드래그합니다. Esc는 선택 취소입니다. 여러 모니터와 음수 화면 좌표를 지원합니다.
2. 패널을 감지 영역 밖으로 옮깁니다. 패널이 영역과 겹치면 감지를 시작할 수 없습니다.
3. **단축키 변경**을 누르고 원하는 키 또는 Ctrl/Alt/Shift 조합을 누릅니다. 기본값은 **F8**입니다. 다른 프로그램이 사용하는 키는 오류를 표시하고 기존 키를 유지합니다. Esc는 변경 취소입니다.
4. **감지 간격 (초)**에 원하는 값을 입력합니다. 0.05~60초 범위이며 기본값은 0.3초입니다. 화살표 버튼은 0.05초 단위로 값을 바꿉니다.
5. **최대 클릭 횟수**(총 1~10000회)와 **클릭 후 쿨타임**(0~600초)을 지정합니다. 예를 들어 5회는 처음 클릭을 포함하여 총 5번입니다.
6. 단축키 또는 **감지 시작**을 누릅니다. 설정한 간격만큼 기다린 다음 기준 화면을 저장합니다. 이후 같은 간격마다 기준 화면과 비교합니다. 설정을 바꾸려면 감지를 정지하고 수정한 뒤 다시 시작하세요.
7. RGB 값 차이가 허용값을 넘는 픽셀이 있으면 그 픽셀을 한 번 클릭합니다. 여러 위치가 바뀌면 위에서 아래, 왼쪽에서 오른쪽 순서로 처음 확인한 픽셀을 클릭합니다. 횟수가 남아 있으면 쿨타임을 거쳐 감지를 계속하고, 총 횟수에 도달하면 자동 정지합니다.
8. 오른쪽 매크로를 연결하려면 **변화 위치 클릭 후 아래 매크로 실행**을 체크합니다. 체크하지 않으면 기존처럼 변화 위치 클릭만 실행합니다.
9. 감지·매크로·쿨타임 중 같은 단축키 또는 **정지** 버튼으로 언제든 끕니다. 다시 켜면 새로운 기준 화면과 0회부터 시작합니다.

## 매크로 직접 편집

오른쪽에서 동작 종류와 값을 선택하고 **추가**를 누르세요. 목록에서 동작을 선택해 값을 바꾼 뒤 **선택 동작 수정**으로 적용합니다. **위로 / 아래로 / 삭제**로 순서를 편집합니다.

| 동작 | 설정 |
| --- | --- |
| 지정 좌표 클릭 | 화면 전체 X/Y 좌표, 왼쪽·오른쪽·가운데 버튼. **화면에서 좌표 지정**으로 선택 (Esc 취소) |
| 문자 입력 | 한글 포함 최대 2000자. 줄바꿈은 Enter, 탭 문자는 Tab |
| 키 / 조합키 입력 | 키 입력 칸에서 Enter, Tab, Ctrl+A 등의 키를 직접 누름 |
| 지연 | 0~600000ms. 1000ms는 1초 |
| 마우스 이동 / 휠 | 지정 좌표로 이동 또는 해당 위치에서 휠. 휠 값 +120은 위로 한 칸, -120은 아래로 한 칸 |
| 키 누르기 / 떼기 | 눌림·해제를 별도 단계로 편집. 조합 동작을 직접 구성 가능 |
| 마우스 버튼 누르기 / 떼기 | 버튼과 좌표를 별도로 편집. 이동과 조합하여 드래그 구성 가능 |
| 추가 변화 위치 클릭 | 최초 필수 클릭 외에 현재 감지 위치를 추가로 클릭할 때 사용 |

- **목록 반복**은 하나의 변화가 감지된 뒤 목록 전체를 실행할 횟수입니다(1~10000회). 왼쪽 **최대 클릭 횟수**는 감지 이벤트 횟수이며, 목록 속 추가 클릭은 여기에 포함되지 않습니다.
- 실행 흐름: **변화 위치 1회 클릭 → 목록을 설정 횟수만큼 재생 → 쿨타임 → 다음 감지**. 매크로 실행 중에는 새 변화를 감지하지 않습니다. 쿨타임은 매크로 완료 시점부터 셉니다.
- **매크로만 테스트 (2초 후)**는 영역 선택 없이 목록만 재생합니다. 2초 안에 입력할 창에 초점을 주세요. 테스트는 최초 변화 위치 클릭을 수행하지 않으며 '추가 변화 위치 클릭' 단계는 사용할 수 없습니다.
- 입력 대상은 현재 초점을 가진 창이며, 좌표는 전체 화면의 절대 좌표입니다. 입력할 칸을 먼저 클릭하거나 녹화에 포함하세요. 모니터 배치가 바뀌면 좌표를 수정하세요.
- 오류나 정지 시 이후 동작을 취소하고 매크로가 누른 채로 둔 키·마우스 버튼을 해제합니다. 이미 실행한 입력은 되돌리지 않습니다.
- 감지 ON/OFF 단축키와 같은 주 키를 매크로에 넣으면 시작을 거부합니다. 감지 단축키를 변경하거나 해당 동작을 편집하세요.

## 자동 녹화

1. 오른쪽 **녹화**를 누릅니다. **2초 뒤** 녹화가 시작됩니다.
2. 대상 창에서 키보드 입력, 클릭, 드래그, 마우스 이동, 세로 휠 조작을 합니다.
3. **F9** 또는 녹화 창의 **녹화 완료**를 누릅니다. 취소하면 기존 목록을 유지합니다. 완료하면 기존 목록을 녹화 목록으로 교체합니다.
4. 기록된 누르기·떼기·이동·휠·지연을 목록에서 검토하고 수정한 뒤 저장하거나 재생합니다.

- 녹화 중에만 시스템 입력을 수집합니다. 녹화 창 내부의 키/마우스 조작, F9 종료 키, 프로그램이 생성한 입력은 기록하지 않습니다.
- 마우스 이동은 최대 50ms마다 기록합니다. 동작 간 시간을 지연 단계로 저장하며 최대 10분 또는 2000개 단계 근처에서 자동 종료됩니다(지연도 한 단계).
- 녹화 결과는 메모리에만 있으며 **저장**을 눌렀을 때만 선택한 파일에 기록합니다. 네트워크 전송은 없습니다.
- 녹화는 가상 키 코드 기반으로 재생합니다. 한/영 IME 상태, 키보드 배열, 관리자 권한에 따라 문자 결과가 달라질 수 있습니다. 같은 문자 입력이 중요하면 해당 부분을 '문자 입력' 단계로 바꾸세요. 가로 휠과 보조 마우스 버튼은 지원하지 않습니다.

## 저장 / 불러오기

**저장**과 **불러오기**는 자체 `.rcmacro` 형식을 사용합니다. 동작 목록과 목록 반복 횟수가 저장되며, 영역·감지 간격·쿨타임·감지 단축키는 포함하지 않습니다. 첨부 참고 프로그램의 `.m` 파일과는 호환되지 않습니다. 파일을 불러와도 자동 실행하지 않습니다.

## 중복 클릭 방지 동작

- 매크로 실행 중과 쿨타임 동안은 선택한 영역 전체의 변화를 무시합니다.
- 쿨타임 종료 후 첫 검사 화면을 새 기준으로 저장하고, 그 다음 검사부터 새 변화를 찾습니다. 클릭 후 바뀐 화면이 그대로 유지되면 다시 클릭하지 않습니다.
- 쿨타임 0초여도 다음 검사에서 기준 화면을 한 번 갱신하여 클릭 직후 화면 변화에 다시 반응하는 것을 줄입니다.
- 쿨타임 중 나타났다가 유지된 변화도 새 기준에 포함되므로 그 변화만으로 추가 클릭하지 않습니다. 종료 후 새로 발생한 변화에 반응합니다.
- 같은 이미지가 사라졌다가 나중에 다시 나타나는 전환은 새로운 변화로 취급합니다. 이미지 이력이나 물체의 의미를 구분하는 기능은 없습니다.
- 상태 표시에서 누적/총 클릭 횟수와 쿨타임 남은 시간을 확인할 수 있습니다. 실제 재개 시점은 감지 간격에 따라 쿨타임보다 늦어질 수 있습니다.

**색상 차이 허용값** 기본값 0은 1픽셀의 작은 변화도 감지합니다. 미세한 색 변화가 원치 않는 클릭을 일으키면 값을 높이세요(0~254). 설정은 프로그램 실행 중 유지되며 재실행하면 초기화됩니다.

## 동작 범위

- 화면에 실제 보이는 픽셀을 비교합니다. 가려진 창의 내용이나 화면 밖 영역은 감지하지 않습니다. 시계, 동영상, 커서 효과, 알림도 화면 변화가 될 수 있습니다.
- 창 이동/최소화/크기 변경 시 감지를 중단합니다. 감지 중 패널이 영역에 겹치거나 선택 영역이 화면 밖이 되면 중단합니다.
- 입력 실패 시 재시도하지 않고 이후 동작을 중단합니다. 관리자 권한으로 실행되는 대상은 Windows 입력 권한 제한으로 입력되지 않을 수 있습니다. 일부 앱은 Unicode 문자 입력을 지원하지 않을 수 있습니다.
- 화면 캡처는 메모리에서만 비교하며 파일 저장이나 네트워크 전송을 하지 않습니다.
- 설정한 감지 간격 사이에 나타났다 사라지는 변화는 놓칠 수 있습니다. Windows 타이머와 화면 처리 부하에 따라 실제 간격이 길어질 수 있으며 정밀 실시간 타이밍을 보장하지 않습니다. 짧은 간격과 큰 영역을 함께 사용하면 CPU 사용량이 증가할 수 있습니다.

## 검증 / 개발

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1
```

픽셀 비교, 반복 제한·쿨타임 경계·중복 방지, 매크로 순서·지연·취소·오류 중단, 녹화 이벤트 시간, 저장/불러오기와 XML 검증을 확인합니다. 자동 테스트는 실제 마우스·키보드 입력이나 시스템 녹화 후크를 사용하지 않습니다. 실제 녹화·단축키·재생은 Windows 데스크톱에서 별도 확인해야 합니다.

소스는 `src/Program.cs`, `src/Macro.cs`, `src/MacroEditor.cs`, `src/Recorder.cs`이며 빌드는 Windows에 포함된 .NET Framework C# 컴파일러를 사용합니다.
