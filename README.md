# 영역 변화 클릭 매크로

Windows용 컨트롤 패널 프로그램입니다. 사각형 영역을 직접 선택하고, 1초 간격으로 변화를 확인하여 변화 위치를 **한 번 왼쪽 클릭한 뒤 자동 정지**합니다.

## 실행

Windows 10/11과 .NET Framework 4.8 환경에서 사용합니다. Python이나 추가 패키지는 필요하지 않습니다.

1. 저장소를 다운로드하고 압축을 풉니다.
2. 프로젝트 폴더에서 Windows PowerShell로 `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1`을 실행합니다. 이 옵션은 해당 실행에만 적용됩니다.
3. 생성된 `dist\RegionChangeClicker.exe`를 실행합니다.

GitHub Actions의 **Windows build / Artifacts / RegionChangeClicker-Windows**에서도 빌드된 실행 파일을 받을 수 있습니다.

## 사용 방법

1. **영역 선택**을 누르고 화면에서 사각형을 드래그합니다. Esc는 선택 취소입니다. 여러 모니터와 음수 화면 좌표를 지원합니다.
2. 패널을 감지 영역 밖으로 옮깁니다. 패널이 영역과 겹치면 감지를 시작할 수 없습니다.
3. **단축키 변경**을 누르고 원하는 키 또는 Ctrl/Alt/Shift 조합을 누릅니다. 기본값은 **F8**입니다. 다른 프로그램이 사용하는 키는 오류를 표시하고 기존 키를 유지합니다. Esc는 변경 취소입니다.
4. 단축키 또는 **감지 시작**을 누릅니다. 1초 동안 화면이 안정되기를 기다린 다음 기준 화면을 저장합니다. 이후 매 1초마다 기준 화면과 비교합니다.
5. RGB 값 차이가 허용값을 넘는 픽셀이 있으면 그 픽셀을 한 번 클릭하고 멈춥니다. 여러 위치가 바뀌면 위에서 아래, 왼쪽에서 오른쪽 순서로 처음 확인한 픽셀을 클릭합니다.
6. 감지 중 같은 단축키 또는 **감지 정지**로 언제든 끕니다. 다시 켜면 새로운 기준 화면을 저장합니다.

**색상 차이 허용값** 기본값 0은 1픽셀의 작은 변화도 감지합니다. 미세한 색 변화가 원치 않는 클릭을 일으키면 값을 높이세요(0~254). 단축키와 영역은 프로그램 실행 중 유지되며 재실행하면 초기화됩니다.

## 동작 범위

- 화면에 실제 보이는 픽셀을 비교합니다. 가려진 창의 내용이나 화면 밖 영역은 감지하지 않습니다. 시계, 동영상, 커서 효과, 알림도 화면 변화가 될 수 있습니다.
- 창 이동/최소화/크기 변경 시 감지를 중단합니다. 감지 중 패널이 영역에 겹치거나 선택 영역이 화면 밖이 되면 중단합니다.
- 클릭 실패 시 재시도하지 않고 오류를 표시합니다. 관리자 권한으로 실행되는 대상은 Windows 입력 권한 제한으로 클릭되지 않을 수 있습니다.
- 화면 캡처는 메모리에서만 비교하며 파일 저장이나 네트워크 전송을 하지 않습니다.
- 1초 사이에 나타났다 사라지는 변화는 놓칠 수 있습니다. 큰 화면 영역은 처리 시간이 길어져 실제 검사 간격이 늘어날 수 있습니다.

## 검증 / 개발

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1
```

픽셀 비교, 허용값 경계, 변화 위치, 1회 실행, 수동 정지, 실패 후 정지 유지, 재시작 기준 초기화를 검증합니다. 테스트는 실제 마우스 클릭을 전송하지 않습니다. 화면 선택·전역 단축키·실제 클릭은 Windows 데스크톱에서 별도 확인해야 합니다.

소스는 `src/Program.cs`, 빌드는 Windows에 포함된 .NET Framework C# 컴파일러를 사용합니다.
