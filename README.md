# 영역 변화 클릭 매크로

Windows용 컨트롤 패널 프로그램입니다. 사각형 영역을 직접 선택하고, 1초 간격으로 변화를 확인하여 **설정한 클릭·키보드·지연 동작을 순서대로 한 번 실행한 뒤 자동 정지**합니다. 기본 매크로는 기존과 동일한 '변화 위치 왼쪽 클릭' 한 동작입니다.

## 실행

Windows 10/11과 .NET Framework 4.8 환경에서 사용합니다. Python이나 추가 패키지는 필요하지 않습니다.

1. 저장소를 다운로드하고 압축을 풉니다.
2. 프로젝트 폴더에서 Windows PowerShell로 `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1`을 실행합니다. 이 옵션은 해당 실행에만 적용됩니다.
3. 생성된 `dist\RegionChangeClicker.exe`를 실행합니다.

GitHub Actions의 **Windows build / Artifacts / RegionChangeClicker-Windows**에서도 빌드된 실행 파일을 받을 수 있습니다.

## 사용 방법

1. **영역 선택**을 누르고 화면에서 사각형을 드래그합니다. Esc는 선택 취소입니다. 여러 모니터와 음수 화면 좌표를 지원합니다.
2. 패널을 감지 영역 밖으로 옮깁니다. 패널이 영역과 겹치면 감지를 시작할 수 없습니다.
3. **단축키 변경**을 누르고 원하는 키 또는 Ctrl/Alt/Shift 조합을 누릅니다. 기본값은 **F8**입니다. 다른 프로그램이 사용하는 키는 오류를 표시하고 기존 키를 유지합니다. Esc는 변경 취소입니다.
4. 단축키 또는 **감지 시작**을 누릅니다. 1초 동안 화면이 안정되기를 기다린 다음 기준 화면을 저장합니다. 이후 매 1초마다 기준 화면과 비교합니다.
5. RGB 값 차이가 허용값을 넘는 픽셀이 있으면 감지를 중단하고 아래의 매크로 목록을 순서대로 한 번 실행합니다. 여러 위치가 바뀌면 위에서 아래, 왼쪽에서 오른쪽 순서로 처음 확인한 픽셀을 '변화 위치'로 사용합니다.
6. 감지 중 또는 매크로 실행 중 같은 단축키나 **감지 정지 / 매크로 정지**를 누르면 남은 동작을 취소합니다. 다시 켜면 새로운 기준 화면을 저장합니다.

## 매크로 연결 설정

패널 아래에서 동작 종류와 값을 고른 후 **추가**를 누릅니다. 목록에서 동작을 선택하면 값을 불러오며, **선택 동작 수정**을 눌러 변경을 적용합니다. **위로 / 아래로 / 삭제**로 실행 순서를 편집합니다.

| 동작 | 설정 |
| --- | --- |
| 변화 위치 클릭 | 이번에 감지된 픽셀을 왼쪽 또는 오른쪽으로 1회 클릭 |
| 지정 좌표 클릭 | 화면 전체 기준 X/Y 좌표를 1회 클릭. **화면에서 좌표 지정**으로 선택 가능 (Esc 취소) |
| 문자 입력 | 한글 포함 일반 문자 최대 2000자. 줄바꿈은 Enter, 탭 문자는 Tab으로 전송 |
| 키 / 조합키 입력 | 키 칸을 클릭한 후 Enter, Tab, 방향키, Ctrl+A 등의 키를 직접 눌러 지정 |
| 지연 (ms) | 0~600000ms 대기. 1000ms = 1초. 대기 중에도 즉시 정지 가능 |

예: **변화 위치 클릭 → 지연 500ms → 지정 좌표 클릭 → 문자 입력 '완료' → Enter**.

- 기본 '변화 위치 클릭'도 목록에서 삭제하거나 위치를 옮길 수 있습니다. 목록에 없는 클릭을 자동으로 추가하지 않습니다.
- 문자는 현재 입력 초점이 있는 창에 전송됩니다. 보통 먼저 지정 좌표로 입력 칸을 클릭하고 필요한 지연을 추가하세요. 별도의 대상 창 고정 기능은 없습니다.
- ON/OFF 단축키와 동일한 키 입력 동작은 시작 시 거부합니다. 매크로가 자기 자신을 정지시키는 상황을 방지합니다.
- 동작은 1~100개까지 설정할 수 있습니다. 감지 시작 시 목록을 고정하며, 실행이 끝나거나 정지한 뒤 다시 편집할 수 있습니다.
- 실행은 1회이며 자동 반복하지 않습니다. 완료·오류·사용자 정지 모두 대기 상태로 돌아갑니다. 정지는 이미 실행된 클릭이나 문자를 되돌리지는 않습니다.
- 매크로 목록은 현재 실행 중에만 유지됩니다. 프로그램 종료 시 저장하지 않습니다.

**색상 차이 허용값** 기본값 0은 1픽셀의 작은 변화도 감지합니다. 미세한 색 변화가 원치 않는 클릭을 일으키면 값을 높이세요(0~254). 단축키와 영역은 프로그램 실행 중 유지되며 재실행하면 초기화됩니다.

## 동작 범위

- 화면에 실제 보이는 픽셀을 비교합니다. 가려진 창의 내용이나 화면 밖 영역은 감지하지 않습니다. 시계, 동영상, 커서 효과, 알림도 화면 변화가 될 수 있습니다.
- 창 이동/최소화/크기 변경 시 감지를 중단합니다. 감지 중 패널이 영역에 겹치거나 선택 영역이 화면 밖이 되면 중단합니다.
- 클릭·키보드 전송 실패 시 재시도하지 않고 이후 동작을 중단합니다. 관리자 권한으로 실행되는 대상은 Windows 입력 권한 제한으로 입력되지 않을 수 있습니다. 일부 게임 등은 Unicode 문자 입력을 지원하지 않을 수 있습니다.
- 화면 캡처는 메모리에서만 비교하며 파일 저장이나 네트워크 전송을 하지 않습니다.
- 1초 사이에 나타났다 사라지는 변화는 놓칠 수 있습니다. 큰 화면 영역은 처리 시간이 길어져 실제 검사 간격이 늘어날 수 있습니다.

## 검증 / 개발

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1
```

픽셀 비교, 허용값 경계, 변화 위치, 1회 실행, 수동 정지, 실패 후 정지 유지, 재시작 기준 초기화와 매크로 순서·지연·취소·오류 중단·입력값 검증을 확인합니다. 자동 테스트는 실제 마우스나 키보드 입력을 전송하지 않습니다. 화면 선택·전역 단축키·실제 입력은 Windows 데스크톱에서 별도 확인해야 합니다.

소스는 `src/Program.cs`, `src/Macro.cs`, `src/MacroEditor.cs`이며 빌드는 Windows에 포함된 .NET Framework C# 컴파일러를 사용합니다.
